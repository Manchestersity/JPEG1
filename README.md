# Документация функций
## get_file_content
Параметры
FILE *fs_file - указатель на открытый файл файловой системы
const char *filename - имя файла для чтения (строка)
char * - строка с содержимым файла (необходимо free), NULL если файл не найден или ошибка

FILE *fs_file - указатель на открытый файл файловой системы
const char *filename - имя файла для удаления (строка)
Возвращаемое значение
nt - 0 при успешном удалении, -1 при ошибке

## add_new_file
Прототип
Добавляет новый файл в конец файловой системы.
Параметры  
- fs_path (const char*) — путь к файлу с файловой системой  
- filename (const char*) — имя нового файла  
- content (const char*) — содержимое файла
Возвращает
- int — 0 при успехе, -1 при ошибке
## edit_file_content
Прототип
Изменяет содержимое файла, имя файла сохраняется.
Параметры
- fs_path (const char*) — путь к файлу с файловой системой  
- filename (const char*) — имя файла для изменения  
- new_content (const char*) — новое содержимое
Возвращает
- int — 0 при успехе, -1 если файл не найден или ошибка
 Использование файловой системы
Команды вводятся в консоли
- создать <путь>  
  Создаёт новый файл по указанному пути.
- удалить <путь>  
  Удаляет указанный файл.
- изменить <путь>  
  Позволяет ввести новое содержимое файла.
- посмотреть <путь>  
  Выводит содержимое файла на экран.
- выход  
  Завершает работу программы.
