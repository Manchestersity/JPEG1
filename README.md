## Функция: open_or_create_fs

**Описание:** Открывает файл файловой системы для чтения и записи. Если файла не существует, создаёт новый.

**Параметры:**

- `const char *filename` — строка, путь к файлу файловой системы.

**Возвращаемое значение:**

- `FILE *` — указатель на открытый файл файловой системы, либо NULL при ошибке.

---

## Функция: get_file_content
